
一、定位

1. 这是“酒类优先”的分类页，不是普通通用商城类目页；
2. 页面宽度按 375px 设计，适合手机浏览器查看；
3. 页面应支持从 mobile/index.html 进入，并提供返回 ./index.html 的入口。

二、页面结构

1. 顶部栏：返回按钮、页面标题、搜索框、筛选按钮；
2. 左侧一级分类导航，至少包含：
   - 红酒
   - 白酒
   - 威士忌
   - 香槟/起泡酒
   - 清酒
   - 精酿啤酒
   - 礼盒
   - 瑕疵酒专区
3. 右侧内容区包含：
   - banner 区
   - 二级筛选标签（品牌、产区、价格带、口感、适饮场景）
   - 酒款商品列表或双列卡片
4. 商品卡片除基础价格外，必须展示：
   - 酒名
   - 品牌
   - 产区
   - 年份
   - 口感标签
   - 适饮窗口
   - 瑕疵酒标识
   - 盲盒可入池标识
5. 页面内必须增加以下酒类专属模块卡片：
   - 品牌故事入口
   - 产区地图入口
   - 搭餐建议入口
   - 口感档案入口
   - 真伪/批次溯源入口
   - 数字酒窖入口
   - AI 侍酒师入口

三、必须包含的交互要点

1. 左侧一级分类点击后，右侧内容联动切换；
2. 顶部搜索支持按酒名/品牌关键字前端筛选；
3. 筛选抽屉必须支持：
   - 品牌筛选
   - 产区筛选
   - 价格区间
   - 口感维度筛选
   - 是否瑕疵酒
   - 是否可入盲盒
4. 支持“综合 / 销量 / 价格 / 上新”排序切换；
5. 商品卡片支持“加入购物车”和“查看详情”两个入口；
6. 点击“口感档案”可弹出简易口感弹窗；
7. 点击“产区地图”可弹出地图说明卡；
8. 点击“搭餐建议”展示底部弹层；
9. 点击“真伪/批次溯源”可展示批次信息弹窗；
10. 页面底部悬浮 AI 侍酒师入口；
11. 如商品属于福袋盲盒池或瑕疵酒专区，要展示资格限制或风险提示；
12. 页面支持空状态与无结果状态展示。

四、必须体现的酒类专属内容

1. 品牌故事短卡：展示品牌历史一句话摘要；
2. 产区地图短卡：用占位图表示产区位置；
3. 搭餐建议：例如“适配牛排、烤羊排、硬质奶酪”；
4. 口感档案：酸度/甜度/单宁/酒体/香气关键词；
5. 适饮窗口：例如“2026-2032 适饮”；
6. 真伪/批次溯源：展示批次号、防伪码入口；
7. 数字酒窖入口：显示“支持入窖”或“暂不支持”；
8. AI 侍酒师入口：支持快捷提问。

2. 一级分类区与内容区要有清晰层级；
3. 页面内样式和脚本直接写在 HTML 中；
4. 所有跳转使用相对路径；
5. 文案全部中文；
6. 最终直接输出完整 html 代码，不要输出解释。
