请为“高端酒类品鉴会活动”设计一套移动端小程序界面（偏微信小程序风格），要求如下：

【场景设定】

- 用户在线下参加酒类品鉴会
- 小程序用于签到 + 参与抽奖（实际抽奖在线下进行）
- 小程序主要提供：参与感、互动感、现场氛围

【页面结构】

1. 顶部：活动信息
   - 活动名称（如：红酒品鉴夜）
   - 时间 + 地点
   - 背景图：模糊酒杯/葡萄酒场景

2. 中间：签到状态
   - 按钮：
     - 未签到：按钮「立即签到」
     - 已签到：显示「已签到 ✔」
   - 动效：轻微缩放

3. 抽奖参与区（重点）
   - 显示当前参与人数
   - 显示奖池（如：一等奖 红酒1瓶）
   - 按钮：「参与抽奖」
   - 提示：实际开奖在现场进行

4. 社交互动区
   - 显示参与用户头像（横向滚动）
   - 文案：「已有 128 人参与」

5. 底部氛围
   - 浮动文案：
     “举杯之间，惊喜即将揭晓 🍷”

【交互效果】

- 按钮点击带 scale 动画
- 卡片进入有 fade+slide 动画
- 背景有轻微渐变流动效果

【输出要求】

- 输出 HTML + CSS（可转 Vue / 小程序）
- 结构清晰，可组件化
- 所有颜色使用变量定义
