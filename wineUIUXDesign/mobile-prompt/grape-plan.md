请生成一个“葡萄酒养成计划”移动端页面 grape-plan.html，使用纯 HTML + CSS + 原生 JavaScript，实现一个具有真实感的养成互动体验页面。

【核心目标】
不是普通页面，而是一个具有“游戏感 + 成长感 + 操作反馈”的养成系统，用户要有持续点击和参与欲望。

---

【核心功能（必须实现）】

一、🌳 “真实感葡萄树”展示（重点）

1. 页面中央必须有一棵“葡萄树/藤”的可视化展示
2. 使用 SVG 或 div 模拟一棵树（不要只是图片）
3. 支持 3 个成长阶段：
   - 幼苗（小）
   - 成长期（中）
   - 成熟期（大 + 有葡萄）
4. 切换阶段时要有动画过渡（scale + 渐变）
5. 成熟期要出现“葡萄果实元素”（小圆点或SVG）

👉 强调：必须让用户感觉“树是在长大”

---

二、💧 浇水交互（重点）

1. 页面有明显“浇水按钮”
2. 点击后触发动画：
   - 水滴从上往下掉（CSS animation）
   - 水滴落到树上消失
3. 浇水后触发：
   - 树轻微放大（scale 1 → 1.05 → 1）
   - 叶子轻微摇动（rotate动画）
4. 同时成长值增加

👉 强调：必须有视觉反馈，不只是数值变化

---

三、📈 成长系统

1. 页面显示：
   - 当前成长值（如 45/100）
   - 进度条（带动画）
2. 每次浇水：
   - 成长值增加
   - 进度条平滑增长
3. 达到阶段阈值：
   - 自动升级树形态（触发动画）

---

四、🌞 资源系统（增强真实感）
页面展示：

- 水分值（Water）
- 阳光值（Sunlight）
- 成长值（Growth）

浇水 → 增加 water 和 growth

---

五、👥 社交互动（简单但要有）

- 显示好友列表头像（横向滚动）
- 显示：
  “已有 128 人参与养成”
- 可有按钮：
  “去看看好友的葡萄树”

---

六、🎁 成熟奖励（激励）

- 成熟后提示：
  “你的葡萄已成熟 🍇”
- 奖励：
  - 积分
  - 优惠券
  - 试饮资格
- 弹窗动画（scale + fade）

---

【动效要求（重点）】
必须实现这些动画：

1. 水滴动画（drop）
2. 树成长动画（scale + opacity）
3. 叶子轻微摆动（keyframes rotate）
4. 进度条平滑变化（transition）
5. 按钮点击反馈（scale 0.96 → 1）

---

【交互细节】

- 按钮点击有震动感（视觉模拟）
- 动画时长：200ms ~ 400ms
- easing：ease-out

---

【输出要求】

1. 单文件 HTML，可直接运行
2. 所有 CSS 写在 style 中
3. 使用原生 JS 控制状态
4. 不使用第三方库
5. mock 数据模拟成长逻辑
6. 代码结构清晰，方便后续改成小程序

---

【关键强调（非常重要）】
不要生成“静态展示页面”，必须是：
👉 有动画 + 有成长 + 有反馈 + 有互动感

否则页面将没有用户吸引力。
