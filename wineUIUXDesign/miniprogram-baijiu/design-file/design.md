# 高端白酒电商微信小程序原型设计提示词

## 目标

设计一套适合销售**中高端白酒**的微信小程序可编辑原型稿。

项目定位为：

> 高端白酒电商 + 营销活动 + 酒局社交 + 溯源防伪 + 数字藏酒 + AR选购体验

目标用户包括：

1. 白酒个人消费者
2. 礼品采购用户
3. 企业团购客户
4. 酒局社交用户
5. 收藏型白酒用户
6. 对正品保障、产地溯源、品牌故事敏感的高净值用户

设计需要体现：

- 品质感
- 信任感
- 收藏价值
- 礼赠属性
- 中国传统文化感
- 高端白酒品牌调性

---

## 整体风格

整体采用 **“东方高端白酒 · 暗金奢华风”**。

视觉关键词：

```text
深色背景 / 金色描边 / 红色强调 / 宣纸卡片 / 国风纹理 / 山水意境 / 酒坛器物 / 礼盒质感 / 收藏感
```

整体氛围参考：

```text
高端白酒品牌官网
中式山水画
黑金礼盒包装
国风会员卡
古法酿造故事
高端商务礼赠场景
```

风格要求：

- 页面背景以深色为主，突出高级感
- 商品卡片使用米白、宣纸色作为内容承载
- 按钮使用鎏金渐变或深红渐变
- 标题可使用偏宋体、楷体、国风字体风格
- 正文保持清晰易读
- 图标统一使用线性图标，金色或暗金色
- 页面之间必须保持同一套视觉语言
- 不要做成普通超市电商风格
- 不要过度年轻化、可爱化
- 不要使用果酒清新色系

