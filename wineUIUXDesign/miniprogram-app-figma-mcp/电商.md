## 目标

输出一套可直接用于产品评审和前端还原的移动端高保真界面，尺寸基于 `375 x 812` 的移动端标准画板，包含 9 个页面，并保持统一的组件系统、间距体系和视觉风格。

## 整体风格

- 风格定位：微信小程序原生电商风格，简洁、轻盈、可信赖。
- 主色：品牌绿色，建议 `#22C55E` 到 `#16A34A` 之间。
- 辅助色：价格红 `#FF5A36`，浅灰背景 `#F7F8FA`，正文深灰 `#222222`，次级文字灰 `#8C8C8C`。
- 卡片风格：大圆角，轻阴影，白底卡片为主。
- 图片风格：护肤美妆商品图，干净、通透、偏高端。
- 信息密度：中等偏高，保证电商效率，不做过度装饰。

## 设计规范

- 画板宽高：`375 x 812`。
- 页面内容宽度：`343`，即左右边距各 `16`。
- 安全区：
  - 状态栏高度 `44`
  - 顶部导航栏高度 `44`
  - 顶部完整头部安全区 `88`
  - 底部安全区 `34`
  - 带底部安全区的 TabBar 总高度建议 `83`
  - 带底部安全区的主操作栏总高度建议 `84 - 96`
- 圆角：
  - 页面主卡片 `20`
  - 输入框 `18`
  - 小按钮 `16`
  - 商品缩略图 `14`
- 线框与分割：
  - 细分割线 `1`
  - 常规描边 / 弱边框 `1`
- 图标尺寸：
  - 顶部导航图标 `20`
  - TabBar 图标 `22 - 24`
  - 功能入口图标 `24 - 28`
  - 列表辅助图标 / 箭头 `16`
- 阴影：浅阴影即可，避免过重。
- 触控规范：
  - 所有可点击区域最小命中尺寸不低于 `44 x 44`
  - 相邻可点击元素之间最少保留 `8` 的间距
- 间距体系：优先使用 `8 / 12 / 16 / 20 / 24 / 32`。
- 模块尺寸建议：
  - 搜索框高度 `36 - 40`
  - 常规按钮高度 `44`
  - 主要 CTA 按钮高度 `48`
  - 商品卡片缩略图边长 `96 - 156`
  - 宫格功能区单元高度 `64 - 72`
  - 地址卡片 / 订单卡片内边距 `16 - 20`
- 字号建议：
  - 页面标题 `28 / semibold`
  - 模块标题 `18 / semibold`
  - 正文 `14 / regular`
  - 商品标题 `15 - 16 / medium`
  - 价格主文案 `24 - 26 / bold`
  - 辅助说明 `12 / regular`

## 页面详细说明

### 1. 首页

- 顶部标题：`精选好物`
- 顶部右侧保留两个圆形图标按钮。
- 搜索框：占满内容区宽度，提示文案为“搜索商品”。
- 顶部 Banner：绿色春季促销视觉，包含护肤品主图、植物装饰、促销文案和 CTA 按钮。
- 功能宫格：4 个入口，分别为：
  - 新品上架
  - 热门榜
  - 优惠券
  - 会员中心
- 限时秒杀模块：
  - 左侧标题“限时秒杀”
  - 右侧“更多”
  - 中间显示倒计时
  - 下方 3 个商品卡
- 精选推荐模块：
  - 顶部带分类切换标签
  - 下方为双列商品卡瀑布流感受，但版式保持规整
- 底部 TabBar：`首页 / 分类 / 购物车 / 我的`

### 2. 分类页

- 顶部标题：`商品分类`
- 顶部搜索框保留。
- 左侧为一级分类列表，选中态为浅绿色底。
- 右侧为二级分类内容区：
  - 顶部展示“护肤”子分类
  - 下方使用 3 列商品图标/缩略图网格
  - 商品下方要有简短名称
- 页面整体强调“左分类 + 右内容”的经典电商结构。

### 3. 商品详情页

- 顶部有返回箭头，右侧两个图标按钮。
- 顶部大商品图卡片，留白充足，突出单品。
- 商品名称：`SK-II 神仙水 护肤精华露 230ml`
- 价格区：
  - 当前价高亮红色
  - 原价置灰删除线
  - 右侧显示销量
- 权益标签行：如“正品保障 / 7天无理由退换 / 极速发货”
- 规格信息区：已选规格、参数入口
- 评价区：显示用户头像、昵称简写、简评和图片缩略图
- 底部操作栏：
  - 客服
  - 收藏
  - 购物车
  - 加入购物车
  - 立即购买

### 4. 购物车页

- 顶部标题：`购物车`
- 右上角有“编辑”。
- 商品列表至少 3 条：
  - 左侧勾选
  - 中间商品图
  - 商品名称与规格
  - 红色价格
  - 右侧数量步进器
- 下方推荐模块标题：`你可能还喜欢`
- 底部结算栏：
  - 全选
  - 合计金额
  - 去结算按钮，按钮上显示商品数量
- TabBar 中购物车高亮。

### 5. 结算页

  - 详细地址
  - 右侧箭头

  - 运费
  - 优惠券
  - 备注输入位
- 底部栏：
  - 左侧合计金额
  - 右侧提交订单按钮

### 6. 提交订单页

  - 微信支付

  - 银行卡支付

  - 左侧合计金额

### 7. 我的页

  - 优惠券

  - 帮助中心

  - 设置

### 8. 我的订单页
